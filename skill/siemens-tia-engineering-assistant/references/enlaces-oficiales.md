# Enlaces oficiales Siemens

Estos enlaces son puntos de entrada oficiales y deben usarse como redirecciones verificables. La disponibilidad de un documento concreto puede depender del idioma, la cuenta Siemens y la versión instalada.

## Documentación TIA Portal

- [TIA Portal Documentation Portal](https://docs.tia.siemens.cloud/): documentación web central de TIA Portal y productos relacionados.
- [Funciones básicas y atajos del TIA Portal V20](https://docs.tia.siemens.cloud/r/en-us/v20/introduction-to-the-tia-portal/user-interface-and-operation/keyboard-operation-in-the-tia-portal/basic-functions-of-the-tia-portal): referencia oficial del atajo **F1** para abrir la ayuda.
- [Observaciones generales del sistema de información V20](https://docs.tia.siemens.cloud/r/en-us/v20/introduction-to-the-tia-portal/help-on-the-information-system/general-remarks-on-the-information-system): explica la ayuda contextual y su visualización en el Help Viewer o navegador estándar.
- [TIA Portal V20 Technical Slides](https://cache.industry.siemens.com/dl/files/848/109963848/att_1305640/v3/TIA_Portal_V20_technical_slides_EN.pdf): presentación oficial que describe el portal de documentación y las novedades de V20.

## Soporte y manuales

- [Siemens Industry Online Support](https://support.industry.siemens.com/): portal oficial de soporte, manuales, notas de aplicación, descargas y artículos.
- [SIMATIC Manual Collection](https://support.industry.siemens.com/cs/document/109479831/simatic-manual-collection): colección oficial de manuales SIMATIC cuando el recurso esté disponible para la sesión.
- [Readme STEP 7 / WinCC V20](https://support.industry.siemens.com/cs/attachments/109963850/ReadMe_STEP7_WinCC_V20_enUS.pdf): información oficial de producto y cambios de V20.
- [Manual de sistema S7-1200 con referencia SCL](https://support.industry.siemens.com/cs/attachments/109977302/s71200_system_manual_en-US.pdf): referencia oficial que incluye conceptos de programación SCL para S7-1200; usar solo para el ámbito de ese controlador y versión del manual.

## Formación y aprendizaje

- [TIA University de Siemens](https://www.siemens.com/es-es/training/tia-university/): formación y talleres oficiales relacionados con TIA Portal.
- [Portal general Siemens](https://www.siemens.com/): entrada institucional oficial; no usar como fuente técnica si existe una página específica en documentación o soporte.

## Reglas de uso

1. Prioriza el portal de documentación y el Help Viewer local para explicar sintaxis o comportamiento.
2. Usa Industry Online Support para notas de versión, correcciones, manuales y problemas conocidos.
3. Comprueba que el documento corresponda con V18, V19 o V20 y con la CPU o producto aplicable.
4. No presentes un PDF de S7-1200 como regla universal para S7-1500, WinCC u otros productos.
5. Si un enlace devuelve acceso restringido, redirección, página no encontrada o idioma distinto, conserva el enlace como punto oficial pero declara que la evidencia no pudo verificarse en esa sesión.
6. No incluyas credenciales, cookies, tokens ni parámetros privados en una URL compartida.

## Help Viewer local independiente

La URL local no es un enlace web público. Depende del servicio **Siemens TIA Help Viewer Service** instalado en el equipo. Debe tratarse como una fuente local de solo lectura:

- comprobar primero que el servicio esté instalado y en ejecución;
- abrir una ruta de contenido real observada en el navegador, no asumir que `/` será una página válida;
- conservar idioma y versión (`api=V20`, por ejemplo) al registrar la evidencia;
- si el navegador muestra un 404, distinguir entre ruta inválida y servicio detenido;
- si el servicio no está disponible, usar el portal web oficial como fallback.
